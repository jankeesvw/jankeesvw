### Omarchy plugins

Small things for the [Omarchy](https://omarchy.org) bar, mostly built because I wanted them myself. Install any of them with `omarchy plugin add <repo url>`, or find them in the plugin marketplace.

| # | Plugin | What it does | Marketplace |
| --- | --- | --- | --- |
| 1 | [Time Machine](https://github.com/jankeesvw/omarchy-time-machine) | Scheduled restic backups, with a snapshot browser in the bar | [jankeesvw.time-machine](https://plugins.omarchy.org/plugin.html?id=jankeesvw.time-machine) |
| 2 | [Tesla](https://github.com/jankeesvw/omarchy-tesla) | Where your car is, how full it is, and how far that gets you, without keeping it awake | [jankeesvw.tesla](https://plugins.omarchy.org/plugin.html?id=jankeesvw.tesla) |
| 3 | [Notification Center](https://github.com/jankeesvw/omarchy-notification-center) | Every notification you were sent, kept and readable again | [jankeesvw.notification-center](https://plugins.omarchy.org/plugin.html?id=jankeesvw.notification-center) |
| 4 | [Herdr](https://github.com/jankeesvw/omarchy-herdr) | Running herdr servers, every agent inside them, and a click that lands you on the one you picked | [jankeesvw.herdr](https://plugins.omarchy.org/plugin.html?id=jankeesvw.herdr) |
| 5 | [Workspace name](https://github.com/jankeesvw/omarchy-workspace-name) | Name the current workspace, and see that name in the bar | [jankeesvw.workspace-name](https://plugins.omarchy.org/plugin.html?id=jankeesvw.workspace-name) |
| 6 | [UniFi Protect](https://github.com/jankeesvw/omarchy-unifi-protect) | Watch your UniFi Protect cameras from the bar | [jankeesvw.unifi-protect](https://plugins.omarchy.org/plugin.html?id=jankeesvw.unifi-protect) |
| 7 | [Downloads](https://github.com/jankeesvw/omarchy-downloads) | Recent downloads, in a window you can drag files out of | [jankeesvw.downloads](https://plugins.omarchy.org/plugin.html?id=jankeesvw.downloads) |
| 8 | [Gmail Inbox](https://github.com/jankeesvw/omarchy-gmail-inbox) | Unread count in the bar, sender and subject in the panel | [jankeesvw.gmail-inbox](https://plugins.omarchy.org/plugin.html?id=jankeesvw.gmail-inbox) |
| 9 | [Omasweeper](https://github.com/jankeesvw/omasweeper) | Minesweeper, drawn like a TUI | [jankeesvw.omasweeper](https://plugins.omarchy.org/plugin.html?id=jankeesvw.omasweeper) |
| 10 | [Text Transform](https://github.com/jankeesvw/omarchy-text-transform) | Rewrite, translate or fix text with the coding agent Omarchy already runs | [jankeesvw.text-transform](https://plugins.omarchy.org/plugin.html?id=jankeesvw.text-transform) |
| 11 | [Bambu Lab](https://github.com/jankeesvw/omarchy-bambu-lab) | Chamber camera, AMS spools, progress and stop, over your own network | [jankeesvw.bambu-lab](https://plugins.omarchy.org/plugin.html?id=jankeesvw.bambu-lab) |
| 12 | [GitHub Build Monitor](https://github.com/jankeesvw/omarchy-github-build-monitor) | Whether the branch you deploy from is green right now | submitted |
| 13 | [Meetings](https://github.com/jankeesvw/omarchy-meetings) | Your day as a column, with a line where you are in it | submitted |

### Omarchy themes

Themes install differently to plugins, with `omarchy theme install <repo url>`, and then `omarchy theme set` to switch to one later.
