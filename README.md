### Omarchy plugins

Small things for the [Omarchy](https://omarchy.org) bar, mostly built because I wanted them myself. Install any of them with `omarchy plugin add <repo url>`, or find them in the plugin marketplace.

| Plugin | What it does |
| --- | --- |
| [Time Machine](https://github.com/jankeesvw/omarchy-time-machine) | Scheduled restic backups, with a snapshot browser in the bar |
| [Tesla](https://github.com/jankeesvw/omarchy-tesla) | Where your car is, how full it is, and how far that gets you, without keeping it awake |
| [Notification Center](https://github.com/jankeesvw/omarchy-notification-center) | Every notification you were sent, kept and readable again |
| [Herdr](https://github.com/jankeesvw/omarchy-herdr) | Running herdr servers, every agent inside them, and a click that lands you on the one you picked |
| [Workspace name](https://github.com/jankeesvw/omarchy-workspace-name) | Name the current workspace, and see that name in the bar |
| [UniFi Protect](https://github.com/jankeesvw/omarchy-unifi-protect) | Watch your UniFi Protect cameras from the bar |
| [Downloads](https://github.com/jankeesvw/omarchy-downloads) | Recent downloads, in a window you can drag files out of |
| [Gmail Inbox](https://github.com/jankeesvw/omarchy-gmail-inbox) | Unread count in the bar, sender and subject in the panel |
| [Omasweeper](https://github.com/jankeesvw/omasweeper) | Minesweeper, drawn like a TUI |
| [Text Transform](https://github.com/jankeesvw/omarchy-text-transform) | Rewrite, translate or fix text with the coding agent Omarchy already runs |
| [Bambu Lab](https://github.com/jankeesvw/omarchy-bambu-lab) | Chamber camera, AMS spools, progress and stop, over your own network |
| [GitHub Build Monitor](https://github.com/jankeesvw/omarchy-github-build-monitor) | Whether the branch you deploy from is green right now |
| [Meetings](https://github.com/jankeesvw/omarchy-meetings) | Your day as a column, with a line where you are in it |

There is also [a light theme](https://github.com/jankeesvw/omarchy-wbso-ai-theme) built from the WBSO.ai brand colours.
